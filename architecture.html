Personal Documents Tracking — Architecture

Single-user image-to-structured-data pipeline running on persistent free tiers.

Upload (steps 1–2)

Browser asks Vercel for a presigned R2 URL, then PUTs the image bytes directly to R2. File data never traverses Vercel — avoids the Hobby body-size limit and saves function time.

Process (steps 3–6)

Browser pings /api/documents/[id]/process; Vercel relays to Cloud Run with a shared secret. The processor downloads from R2, normalises (HEIC→JPEG, EXIF, resize), classifies via Claude vision, runs the type-specific extractor, and persists fields + reminders to Neon.

Reminders

Vercel Cron hits /api/cron/check-reminders daily at 09:00 UTC. Pending reminders due within 30 days are grouped, rendered to HTML, sent via Resend, then marked sent.

Auth

Google OAuth via Auth.js v5 with a single-email allowlist. JWT session, no DB-backed sessions table. All non-cron API routes call auth() first.
